# Wearly-Ecom-Project-Management
Project management artifacts, product requirements, and MVP scope definition for the Wearly E-Commerce platform
# Wearly — E-Commerce Clothing and Accessories Platform

A modern, high-performance online store for clothing and accessories, built with a robust backend and an intuitive user interface. 

Live Demo: [great-wearly-shop.vercel.app](https://great-wearly-shop.vercel.app/)

---

## Project Overview
* Domain: E-Commerce / Fashion Retail
* Product Stage: MVP (Minimum Viable Product)
* My Role: Project Manager

---

## Tech Stack and Architecture

### Backend (Python)
* Core: Python, Django Rest Framework (DRF)
* Database: PostgreSQL
* Authentication: JWT (SimpleJWT) and Google OAuth
* Asynchronous Tasks and Scheduling: Celery, Celery Beat, Redis

### Frontend (JavaScript/TypeScript)
* Framework: Next.js (App Router)
* Language: TypeScript
* Styling: Tailwind CSS
* State Management and Data Fetching: Redux Toolkit, RTK Query
* Deployment: Vercel

---

## Project Management Achievements and Scope
As the Project Manager, I established the development workflows from scratch, managed cross-functional team communication, and ensured the timely delivery of key features.

### Key Responsibilities and Outcomes:
* SDLC Management: Orchestrated the full Software Development Life Cycle for frontend, backend, and QA streams.
* Process Setup: Configured ClickUp workspace, sprint boards, and a custom 7-stage task lifecycle (Planning, In Progress, In Review, Ready for QA, QA In Progress, Blocked/Rejected, Done).
* Backlog Grooming and Prioritization: Managed the project backlog, ensuring clear Acceptance Criteria and Definition of Done (DoD) for developers.
* Quality Control: Defined and monitored explicit task transitions between Development and QA stages to ensure zero-bug releases for MVP features.
* UX/UI Improvements: Collaborated with designers to simplify the checkout user flow and optimize primary landing pages for better conversion metrics.

## Key Features Delivered (MVP Scope)
1. Seamless Authentication: Secured login via JWT tokens and one-click Google OAuth.
2. Catalog and Search: High-performance product catalog with filtration and sorting (managed via RTK Query).
3. Shopping Cart and Checkout: Optimized user flow for adding items and completing purchases.
4. Background Tasks: Automated inventory updates and scheduling using Celery and Celery Beat.
